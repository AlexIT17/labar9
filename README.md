# Л/р 9 — Копирование файлов NIO

Запустите Main.main() в IntelliJ IDEA с JDK 17 или новее. Рабочая папка
конфигурации запуска — папка проекта labar_9. Библиотеки не нужны.

Как в Л/р 5, создаются file1.txt и file2.txt по 2 000 000 строк, если их ещё нет.
Затем выполняются:
1. Последовательное синхронное копирование через FileChannel и ByteBuffer:
   copy_seq_1.txt и copy_seq_2.txt.
2. Два одновременно запущенных асинхронных копирования через
   AsynchronousFileChannel и CompletionHandler: copy_async_1.txt и copy_async_2.txt.
3. Вывод времени обоих вариантов и побайтовая проверка всех четырёх копий.

Для своих файлов укажите два пути в Run → Edit Configurations → Program arguments.
Можно взять файлы из Л/р 5:

```
"C:\Users\Саша\IdeaProjects\labar_5\file1.txt" "C:\Users\Саша\IdeaProjects\labar_5\file2.txt"
```

Результаты сохраняются в рабочую папку. Существующие результаты заменяются
после полного копирования во временный файл. Исходники должны оставаться
неизменными во время выполнения. Ошибки выводятся в консоль.

NIO копирует байты, сохраняя кодировку, переносы строк и двоичные данные.
flip() переводит буфер из режима заполнения в режим чтения, clear() подготавливает
его к следующему чтению из канала. Частичная запись обрабатывается до конца буфера.

Асинхронные операции продолжаются в CompletionHandler. Основной поток ожидает
оба результата через CompletableFuture.allOf(...).join(). Ожидание результатов
не делает сами операции чтения и записи синхронными. Selector здесь не нужен:
файловые каналы не поддерживают регистрацию в селекторе.

Время зависит от диска и файлового кеша. Один замер не доказывает, что один
способ всегда быстрее другого.
